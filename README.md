# TorqueCraft Moto Atelier

Premium multi-page motorcycle service HTML template.

## Stack
- Tailwind CSS via CDN (Bootstrap removed completely)
- Vanilla JavaScript
- Custom CSS design system
- Barlow Condensed + Manrope
- Inline SVG icons

## Pages
15 working HTML pages are included.

## Motion system
Scroll reveal, magnetic-ready CTAs, image zoom, compressed glass navigation, mobile shutter menu, loader, progress bar, counters, accordions, filters/search, lightbox, theme/RTL persistence, form loading/success states, reduced-motion support.

## Production note
For ThemeForest/client production, compile Tailwind locally with Tailwind CLI/Vite instead of the CDN, then replace demo images, contact data, prices, canonical URL and JSON-LD with real project data.
